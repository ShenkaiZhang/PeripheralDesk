外设台 PeripheralDesk v0.5.0-preview
Windows 10 / 11 x64 预览版，未签名。

运行与升级
1. 从旧版本的托盘右键菜单选择“退出外设台”。
2. 将 Windows ZIP 解压到固定目录，运行 PeripheralDesk.exe。
3. 点击任务栏右侧的外设台图标打开面板。Esc 收起；托盘右键可退出。
不需要另外安装运行库，不需要联网。请勿同时运行多个版本。

第一页：外设
查看已确认在线的外设及系统或设备提供的电量。
切换默认播放设备和麦克风，分别调整设备音量及静音。
未提供电量不等于 0%；接收器插着不代表外设在线。

第二页：应用音量
点击底部“2 / 2 应用音量”。
分别调整浏览器、音乐软件、游戏等应用的音量（0–100%）及静音。
同一软件跨播放设备合并成一条控制，统一调整当前正在播放的会话。
仅显示 Windows 报告处于播放状态的会话；暂停或结束后隐藏。
静音/0% 的活动会话仍保留，以便恢复声音。程序持续输出静音流时也可能显示。
多个会话音量不一致时，滑块显示最大值，拖动后统一。
音量和播放状态通过 Windows 事件实时同步；界面保留控件与位置，不定时重排。
第二页高度固定，应用较多时滚动查看。右上角可手动重新读取。
浏览器按应用控制，不逐标签页控制；受保护、独占模式、ASIO 等声音不保证支持。
程序不录音，不读取音频内容。

开机启动
程序不会自行设置开机启动。
按 Win+R 输入 shell:startup，将指向固定目录 PeripheralDesk.exe 的快捷方式放入。
覆盖升级且路径不变时无需改快捷方式；移动目录后需修改目标路径和起始位置。

卸载
先退出外设台，再删除自启动快捷方式（若曾创建）和解压目录。
程序没有安装服务。

下载校验
同一 GitHub Release 提供 SHA256SUMS.txt。
使用 PowerShell：Get-FileHash -Algorithm SHA256 "下载的ZIP路径"
将结果与 SHA256SUMS.txt 中同名文件的值比较。
